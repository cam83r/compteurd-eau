## 2. Définitions utiles (art. 1)

- **branchement d'eau** : tuyau acheminant l'eau de l'aqueduc vers un immeuble.
- **branchement d'eau combiné** : dessert protection incendie + eau domestique.
- **chambre de compteur** : ouvrage destiné à recevoir un ou plusieurs compteurs.
- **eau domestique** : eau destinée à la consommation et à un usage sanitaire.
- **entrée d'eau** : premier endroit à l'intérieur du bâtiment où le branchement émerge de l'enveloppe.
- **établissement** : immeuble ou partie utilisé par un seul occupant pour un usage autre que résidentiel.

## 11. Annexe I — Méthode de calcul de la demande de pointe

Paramètres : **demande de pointe de référence QPM = 2,3 m³/h (10 gal US)** ; pression théorique 414 kPa (60 PSI) ; méthode des demandes de pointe par appareil ; référence AWWA M22, 2e édition.

1. Inventaire (annexe H, tableaux 1.2 et 1.3).
2. Débit par ligne = quantité × unité.
3. **Q12** = Σ tableau 1.2.
4. **Q13** = Σ tableau 1.3.
5. **Q12P** (pondéré) selon le cas :

**Cas 1** — salle de spectacle, théâtre, cinéma, école, stade, centre sportif, aréna, hôtel, motel, **ou** ≥ 1 toilette à soupape de chasse, **ou** ≥ 1 urinoir à soupape de chasse :
| Plage | Formule |
|---|---|
| 0 < Q12 < 45 | Q12P = Q12 |
| 45 ≤ Q12 ≤ 1 250 | Q12P = (−3×10⁻⁵ × Q12²) + (0,115 × Q12) + 39,145 |
| 1 250 < Q12 ≤ 13 000 | Q12P = (−3×10⁻⁷ × Q12²) + (0,0114 × Q12) + 120,8 |
| Q12 > 13 000 | Q12P = ((Q12 − 3000) × 68/10000) + 153 |

**Cas 2** — autre type d'établissement :
| Plage | Formule |
|---|---|
| 0 < Q12 < 25 | Q12P = (−0,0103 × Q12²) + (0,9846 × Q12) − 0,18 |
| 25 ≤ Q12 ≤ 1 250 | Q12P = (−3×10⁻⁵ × Q12²) + (0,0748 × Q12) + 16,19 |
| Q12 > 1 250 | Q12P = (−2×10⁻⁸ × Q12²) + (0,007 × Q12) + 56,204 |

6. **QPUS = Q13 + Q12P** (USGPM) ; **QPM = QPUS × 0,227** (m³/h).

Contrôle de continuité (calculé, non tiré du PDF) : cas 1 — Q12 = 45 → 44,26 ; 1 250 → 136,02 / 134,58 ; 13 000 → 218,30 / 221,00. Cas 2 — 25 → 18,00 / 18,05 ; 1 250 → 62,81 / 64,92. Les sauts aux bornes sont faibles : la transcription des exposants est cohérente.
